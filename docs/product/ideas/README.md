# Product Ideas

This folder is the in-repository idea inbox.

Use it for rough product thinking that needs more room than a backlog line. Every idea worth keeping also has an item in the [backlog](../product-backlog.md) that links to its file here; the backlog is the list, this folder holds the longer thinking.

## When to add an idea

Add an idea when it could change:

- User journey
- Marketplace trust
- Order lifecycle
- Payment, escrow, refund, or settlement behavior
- Listing quality
- Dispute handling
- Dashboards
- Notifications
- AI assistance
- Operator workflows

## Idea file format

Use [`../templates/feature-idea.md`](../templates/feature-idea.md).

Suggested file naming:

```text
001-short-descriptive-name.md
002-another-product-question.md
```
