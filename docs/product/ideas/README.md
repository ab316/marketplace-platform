# Product Ideas

This folder is the in-repository idea inbox.

Use it for rough product thinking before an idea becomes a feature spec or backlog item.

## When to add an idea

Add an idea when it could change:

- User journey
- Marketplace trust
- Order lifecycle
- Payment, escrow, refund, or settlement behavior
- Listing quality
- Dispute handling
- Dashboards
- Notifications
- AI assistance
- Operator workflows

## Idea file format

Use [`../templates/feature-idea.md`](../templates/feature-idea.md).

Suggested file naming:

```text
001-short-descriptive-name.md
002-another-product-question.md
```
